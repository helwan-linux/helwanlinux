Helwan Memory Game - Ultimate Edition

Overview

Helwan Memory Game is a timed card-matching game developed and adapted for Helwan Linux. Find matching number pairs before the timer runs out, build combo streaks, and unlock the secret Helwan Core difficulty.

Difficulty Levels

  • Easy: 2×4 grid with a 30-second time limit.
  • Normal: 4×4 grid with a 50-second time limit.
  • Hard: 4×4 grid with a 70-second time limit.
  • Helwan Core: Secret 4×6 grid with a 90-second time limit. It unlocks after completing the Hard level.

Gameplay and Scoring

  • Click two cards to reveal their numbers and find matching pairs.
  • A correct match earns 50 points multiplied by the current combo count.
  • Consecutive matches increase the combo multiplier.
  • An incorrect pair resets the combo and deducts 15 points, without allowing the score to fall below zero.
  • Incorrect cards remain visible for one second before turning face down.
  • Completing the board adds a time bonus of 10 points for each second remaining.
  • A wrong match triggers a brief screen shake and a short background flash.
  • The game ends when the timer reaches zero or when all pairs are matched.

Progress and High Scores

  • High scores are stored separately for Easy, Normal, Hard, and Helwan Core.
  • The game saves its data in ~/.local/share/helwan-memory/game_data.json.
  • Completing Hard unlocks the Helwan Core secret level.
  • Unlocked progress and high scores are retained between game sessions.

Controls

ControlAction
Mouse clickSelect menu options and reveal cards
Pause buttonPause the game
Resume buttonContinue a paused game
Menu buttonReturn to the main menu
EnterReturn to the main menu after winning or losing

Game Menus

  • Main Menu: Start a difficulty level, view High Scores, open About, or Exit.
  • High Scores: View the saved best score for each difficulty.
  • About: Displays the game edition and its key features.
  • In-Game: Use Menu to return to the main menu or Pause to pause the game. The Pause button changes to Resume while paused.
  • Victory / Game Over: Displays the result and final score.
