Helwan Pong - Ultimate Edition

Overview

Helwan Pong is a classic arcade paddle game designed for the Helwan Linux environment. Play against an AI opponent in a points-based match or a timed 60-second match. The ball gradually becomes faster as rallies continue.

Game Modes

  • First to 5 Points: The match ends when either player reaches five points.
  • Timed Match: Play for 60 seconds. The player with the higher score wins.

Gameplay Features

  • Play against an AI-controlled opponent.
  • The ball speeds up progressively after each paddle hit, making longer rallies more challenging.
  • The ball changes to an alert color after more than four consecutive paddle hits.
  • The ball resets with a random direction after each point.
  • The match displays both scores and, in timed mode, the remaining time.
  • The paddles stay within the top and bottom boundaries of the playing field.

Controls

ControlAction
Up ArrowMove your paddle up
Down ArrowMove your paddle down
PPause the match
Pause buttonPause the match
Mouse clickSelect menu options
EnterReturn to the main menu after the match ends

Game Menus

  • Main Menu: Play Game, About, and Exit.
  • Mode Selection: Choose First to 5 Points or Timed (60s Match).
  • Pause Menu: Resume or return to the Main Menu.
  • Game Over: Displays the final score and the match result.
  • About: Displays the game title and a short description.
