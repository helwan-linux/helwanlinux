Helwan Terminal Guide

Welcome to the Helwan Terminal. This program is your powerful yet simple assistant to manage your system, packages, and repositories without hassle.

What can this tool do for you?

1. System Version (The Version Check)

Commands: الإصدار | version | versión | 版本

Use this when: You need to check the current release and build details of your Helwan Linux system.

  • Instantly prints out system version information.

2. Repository Sync (The Database Refresh)

Commands: مزامنة | sync | sincronizar | 同步

Use this when: You want to fetch the latest package listings and metadata from the official repositories.

  • Keeps your local package databases fully synchronized.

3. Install Packages (The Software Installer)

Commands: تثبيت | install | instalar | 安装

Use this when: You want to add new applications or software packages to your system.

  • Downloads and installs software directly from the repositories.

4. Update System (The System Upgrade)

Commands: تحديث | update | actualizar | 更新

Use this when: You want to upgrade your entire operating system and all installed applications to their latest secure versions.

  • Performs a complete system upgrade in one go.

5. Search Packages - Online (The Remote Finder)

Commands: بحث | search | buscar | 搜索

Use this when: You are looking for a new app or package available in the online repositories.

  • Searches across remote package databases for matching software.

6. Search Packages - Local (The Local Finder)

Commands: بحث_محلي | search-local | buscar-local | 本地搜索

Use this when: You want to check if a specific package is already available or installed locally.

  • Quickly queries your local cache and installed software list.

7. Package Info (The Details Viewer)

Commands: معلومات_الحزمة | pkg-info | info-paquete | 软件包信息

Use this when: You need deep technical details about a specific software package.

  • Displays descriptions, sizes, dependencies, and maintainer info.

8. Local Install (The Direct Installer)

Commands: تثبيت_محلي | local-install | instalar-local | 本地安装

Use this when: You have downloaded a package file locally and want to install it manually.

  • Installs package files straight from your local storage.

9. Clear Cache (The Space Cleaner)

Commands: تفريغ_التخزين_المؤقت | clr-cache | limpiar-caché | 清理缓存

Use this when: Your disk space is running low due to stored temporary installation packages.

  • Clears out old cached packages to free up valuable disk space.

10. Unlock Database (The Unblocker)

Commands: فك_القفل | unlock | desbloquear | 解锁

Use this when: Your package manager gets stuck or throws a "database locked" error.

  • Removes stale lock files so package management can resume.

11. Remove Package (The Uninstaller)

Commands: حذف | remove | eliminar | 删除

Use this when: You no longer need an application and want it completely removed.

  • Uninstalls unwanted software safely from your machine.

12. Autoremove Orphans (The Orphan Cleaner)

Commands: تنظيف_المخلفات | autoremove | limpiar-automatico | 自动清理

Use this when: Leftover dependencies and unused orphaned packages are cluttering your system.

  • Automatically cleans up unneeded dependency packages.

13. System Info (The Branding Tool)

Commands: حلوان | helwan | helwán | 赫尔万

Use this when: You want to display core system branding and identity details.

  • Shows Helwan Linux distribution information and artwork/details.

How to use it?

  1. Open the terminal app from your application menu.
  2. Type any of the supported keywords or commands (in any of the supported languages).
  3. Press enter and follow the on-screen prompts.
  4. Review output messages to confirm execution.

Important Note

This tool is part of the Helwanian Identity project. It is designed to make Linux powerful yet simple and accessible for everyone. You can type commands in Arabic, English, Spanish, or Chinese depending on your preference.
